# 📖 О проекте

Данный репозиторий содержит полный исходный код чита **OneShot**.

Проект публикуется **исключительно в ознакомительных и образовательных целях**.

Большая часть кода была написана несколько лет назад и на сегодняшний день уже не соответствует актуальной версии игры.

---

# ⚠️ Предупреждение

> [!WARNING]
> Это **не готовый чит**.
>
> Проект требует большого количества доработок перед использованием:
>
> * обновление оффсетов;
> * исправление вылетов;
> * переписывание множества функций;
> * адаптация под актуальную версию игры.

Если вы не имеете опыта в:

* Reverse Engineering;
* C++;
* Game Hacking,

то разобраться в проекте будет достаточно сложно.

---

# ❗ Известные проблемы

* ❌ Частые вылеты.
* ❌ Устаревшие оффсеты.
* ❌ Многие функции перестали работать.
* ❌ Нет поддержки ARM64 (ARMv8-A).
* ❌ Часть функционала требует полной переработки.
